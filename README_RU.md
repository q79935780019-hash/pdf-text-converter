# 📄 PDF & Картинки → Текст Конвертер

Мощная программа для Windows которая переводит PDF файлы и картинки в текстовые документы!

## ✨ Что умеет делать эта программа?

### 📄 Распознавание текста из PDF и картинок
- ✅ Загружайте PDF файлы - программа распознает текст со ВСЕХ страниц
- ✅ Загружайте картинки (JPG, PNG, BMP) - переводит картинку в текст
- ✅ Поддерживает русский и английский языки
- ✅ Автоматически исправляет ошибки в распознанном тексте
- ✅ Сохраняйте результат в формате:
  - **TXT** (обычный текстовый файл)
  - **DOCX** (документ Word - можно редактировать в Office)
- ✅ Видно прогресс обработки (прогресс-бар)

### 🖼️ Конвертер картинок в PDF
- ✅ Загружайте картинки
- ✅ Поворачивайте картинку как хотите:
  - Кнопка "Влево" - поворот на 90 градусов
  - Кнопка "Вправо" - поворот на 90 градусов
  - Ввод своего угла (0-360 градусов)
- ✅ Сохраняйте в PDF формате
- ✅ Видно превью картинки перед сохранением
