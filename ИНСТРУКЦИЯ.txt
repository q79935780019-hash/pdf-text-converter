# 🎯 БЫСТРАЯ ИНСТРУКЦИЯ - СКАЧАТЬ И ЗАПУСТИТЬ

## 📥 ШАГ 1: СКАЧАЙТЕ ПАПКУ С ПРОГРАММОЙ

1. Откройте эту ссылку:
   ```
   https://github.com/q79935780019-hash/pdf-text-converter
   ```

2. Нажмите зелёную кнопку **"Code"** (вверху справа)

3. Выберите **"Download ZIP"**

4. Скачается файл `pdf-text-converter-main.zip` 

5. **Распакуйте архив** (правой кнопкой мыши → "Извлечь всё")

## 📁 ЧТО ВЫТАЩИЛОСЬ:


## ⚙️ ШАГ 2: УСТАНОВКА (делается один раз)

### A) Установите Python (нужен только для создания приложения)

1. Откройте https://www.python.org/downloads/
2. Скачайте **Python 3.11** или новее
3. Запустите установщик
4. ⚠️ **ВАЖНО!** При установке ОБЯЗАТЕЛЬНО выберите:
   - ☑️ "Add Python to PATH"
5. Нажимайте "Next" → "Install"
6. Перезагрузите компьютер

### B) Установите Tesseract и Poppler

1. В папке программы найдите файл **`INSTALL_OCR.bat`**
2. **Правой кнопкой мыши** → "Запустить от имени администратора"
3. Следуйте инструкциям в окне (откроются ссылки в браузере)
4. Скачайте и установите Tesseract и Poppler

---

## 🚀 ШАГ 3: СОЗДАНИЕ ПРИЛОЖЕНИЯ (EXE)

1. В папке программы найдите файл **`BUILD_EXE.bat`**
2. **Двойной клик** на него
3. Дождитесь завершения (займет 2-3 минуты)
4. Вы увидите сообщение: **"ГОТОВО!"**

---

## ✨ ШАГ 4: ИСПОЛЬЗУЙТЕ ПРОГРАММУ

1. Откройте папку **`dist`** (внутри папки программы)
2. Найдите файл **`PDFTextConverter.exe`** 
3. **Двойной клик** на него - программа запустится! 🎉

## ❓ ВОПРОСЫ И ОТВЕТЫ

**Q: Почему нужно 3 шага?**
A: Шаг 1 - скачивание, Шаг 2 - установка нужных компонентов, Шаг 3 - создание готовой программы.

**Q: Python после создания EXE можно удалить?**
A: Да! После создания EXE Python больше не нужен. EXE работает отдельно.

**Q: Можно ли скопировать EXE на другой компьютер?**
A: Да! Просто скопируйте файл `PDFTextConverter.exe` куда угодно.

**Q: Как создать ярлык на рабочем столе?**
A: Правой кнопкой на `PDFTextConverter.exe` → "Отправить" → "Рабочий стол (ярлык)"

**Q: Что делает программа?**
A: Конвертирует PDF и картинки в текст, и картинки в PDF с поворотом.
