# 📦 Как создать готовый EXE файл (приложение для Windows)

## ⚡ БЫСТРАЯ ИНСТРУКЦИЯ

Если вы хотите получить готовое приложение которое работает как обычная программа на Windows (без Python):

### Шаг 1: Установите Python (нужен только ДЛЯ СОЗДАНИЯ приложения)
- Скачайте Python с https://www.python.org/ (3.11 или новее)
- При установке **ОБЯЗАТЕЛЬНО** выберите ☑️ "Add Python to PATH"
- Установите обычно (Next → Next → Install)

### Шаг 2: Установите Tesseract и Poppler
- В папке программы найдите файл **`INSTALL_OCR.bat`**
- Запустите его (правой кнопкой мыши → "Запустить от имени администратора")
- Следуйте инструкциям в окне

### Шаг 3: Создайте приложение (EXE)
- В папке программы найдите файл **`СОЗДАТЬ_ПРОГРАММУ.bat`**
- Двойной клик на него
- Дождитесь завершения (займет 2-3 минуты)
- Вы увидите сообщение "ГОТОВО!"

### Шаг 4: Используйте программу
- Откройте папку `dist/`
- Найдите файл **`PDFTextConverter.exe`**
- Двойной клик на него - **программа запустится!**

---

## 📝 ЧТО ПРОИЗОЙДЕТ?

1. **Python используется только для создания EXE** - потом его можно удалить
2. **EXE файл полностью самостоятельный** - не требует Python
3. **Вы можете скопировать EXE куда угодно** на компьютер
4. **Можете создать ярлык** на рабочем столе

---

## ❓ ЧАСТЫЕ ВОПРОСЫ

**Q: Нужен ли Python после создания EXE?**
A: Нет! EXE работает полностью отдельно. Python можно удалить.

**Q: Можно ли скопировать EXE на другой компьютер?**
A: Да! Просто скопируйте файл `PDFTextConverter.exe` и используйте где угодно.

**Q: Где найти готовый EXE?**
A: В папке `dist/` → файл `PDFTextConverter.exe`

**Q: Почему нужны Tesseract и Poppler?**
A: Это библиотеки для распознавания текста из PDF и картинок. Они встроены в EXE.
